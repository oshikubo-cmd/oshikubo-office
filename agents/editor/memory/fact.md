# Fact

## 翔泳社 表記ルール（正本・全文）

（出典: 押久保さん提供 2026-08-18受領、2026-08-20 全文再提供。Web記事の校閲はこのルールで行う）

### 数字表記

- 英数字は1文字の場合、紙は全角・Webは半角。2文字以上は紙・Webともに半角
- 4桁の数字は3桁の左に半角カンマ（西暦年を除く）。例）1,000　987,654
- 5桁以上は「万」「億」「兆」を適宜用いる。例）12兆3,456万7,890円（表などでは別の方法でもよい）
- 日付は原則西暦。元号を用いる場合は括弧で補足。例）2006年6月7日（平成18年）
- ばくぜんとした数は漢字表記。例）数百人　数十年　百十何回。「～」を使う場合は算用数字でもよい（2～3人／12～13歳）
- 分数は「1/2」とせず「2分の1」
- 月の表記は小さな「ヵ」で「○ヵ月」
- 固有名詞・歴史用語は漢数字（九十九里浜　赤穂四十七士）。表記が固定している言葉もそれに従う（三者面談　第1四半期）
- 副詞（頻度など）として使う数は漢数字。例）三つの原因。例外として「一つ」が続く場合は「一つひとつ」と後ろをひらく
- 「￥」は使用せず「円」。例）5,000円なり

### 記号表記

- 記号は原則全角。例）（）「」［］“”！？％＆＃＄・（全角中黒）
- 「！」「？」のあとに全角スペースを一つ入れる。ただし記事・ニュースのタイトル内はスペースなしでOK
- 「！！」「！？」のように二つ続く場合は「!?」のように半角にし、そのあと全角スペース
- ケイ（－）は二字分の「－－」。「池袋－有楽町の地下鉄」などの場合は一文字分
- 「」の中の「」は『』。例）「そう聞かれたら、『僕が好きな動画はこれです』と答えるようにしています」
- 「」や（）内の文末では「。」を入れない
- “”は「“」ではじまり「”」で終わる
- キーボードのキー名は全角［］で囲む。ファイル名・ディレクトリ名は全角「」で囲む
- 「／」は半角ではなく全角
- 環境依存文字（①②…⑳、Ⅰ〜Ⅹ、㍉㌔、㎜㎝、㈱㈲、№℡ 等）は使用しない
- 文中の点は「・・・」「。。。」でなく「……」（三点リーダ2連）
- ©®™は記事では記載しない（フッタの包括表記で対応）。タイアップでクライアント要望が出た場合は定型文で一度営業から断る。それでも要望があればUTF-8の©®™をそのまま掲載（外部配信がなければ表示可能）。タイトルでの使用は広告色が強まる旨を伝えてクライアント判断

### スタイル

- 本文行頭は全角空白を入れる（行頭が括弧の場合も同様）
- 文末表現はコンテンツに応じて「である調」「ですます調」いずれも選択可（初心者向けはですます等）
- 句読点は「、」「。」（「，」「．」不可）。文の最後は「！」や「。」で終わる
- 括弧は句読点の前に挟み込む。例）詳細が表示されます（図1）。
- 技術系用語は基本音引きあり。例）コンピューター／フリークエンシー／マーケター／ユーザー。インタフェース系など業界で揺れる用語は原稿内で自然になるよう統一

### 文献表記

- 文中の引用本は『』で囲み、発行出版社名を表記。例）『キャズム』（翔泳社）によれば、
- 参考資料は「［サイト名／雑誌］『［書名／記事名］』［著者名］、［出版社名］、［発行年月］」の順を基本とする。Web記事はサイト名＋記事タイトルが基本。記事タイトルが長い場合はサイト名に記事URLをリンクでもOK

## 表記統一ルール

- **閉じかぎ括弧 `」` の直後に句点 `。` を付けない**（`」。` は不可）。会話文・引用が文末なら `」` で止める。文が続く場合は `」` に地の文を接続する。校正時は `」。` を検索して句点を削除する。（出典: ユーザー指摘 2026-07-15 孫正義講演レポート校閲）
- **PoC**（POCと書かない）

- **紐づけ**（「紐付け」「ひも付け」と書かない）（出典: id645校閲で統一決定 2026-07-31）
- **匿名リード**（「匿名リード顧客」「匿名ユーザー」と書かない。リード＝見込み顧客のため「顧客」を重ねない）（出典: id645タイトル決定 2026-07-31）
