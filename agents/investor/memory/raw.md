### 横断パターン（複数事例に共通する特徴）

#### `[INSIGHT]` エントリー型は「VCP／チート／ハンドル／カップハンドル／PBB」への回帰が大半。判断軸の型で全部説明がつく
39件中、エントリーの記述はほぼ全て判断軸§3の4型（ハンドルブレイク・新高値ブレイク・PBB・50日線ファーストタッチ）
とVCPブレイクの組み合わせで説明できた。DUKE。式教材の要約と実際の売買が高い精度で一致しており、
**判断軸ファイルの型そのものを見直す必要はない**。目新しい買いポイントの型は見つからなかった。

#### `[INSIGHT]` 「初日エントリー→即損切り→数日以内に間を置かず再エントリー」が独立した運用パターンとして頻出
壽屋(#26)、トヨコー(#37)、Arent(#35)、テスHD(#38)で明確に確認。いずれも「損切り後もウォッチを継続し、
再エントリーの機会を伺っていた」という同一の記述パターンがある。壽屋の要点メモは「初日に損切りしたものの
あきらめずにウォッチ、分析し、きちんと再エントリーできたことが勝因」と明言。
→ 自分のルール.md §1「ダマシは事前の目利きではなく損切りで処理する設計」は**理念だけでなく、
DUKE。自身が実務として反復している型**であることが裏取りできた。押久保が損切り後に「もう終わった銘柄」として
ウォッチをやめてしまうと、この型を再現できない。**損切り後もウォッチリストに残し、再ブレイクを待つ運用**を
明示的な手順として持つ価値がある。

#### `[INSIGHT]` 「警戒モード」への移行時、含み益のある銘柄から順に無理せず利確する運用が繰り返し確認できた
メンバーズ(#13)・プロパティエージェント(#23)・日本電解(#27)・クリーク・アンド・リバー社(#28)・カチタス(#29)で
「2021.11.24配信の緊急メルマガ（警戒モード）でリスク量を減らす方向へ舵を切る」という**ほぼ同一の文言**が
繰り返し登場する（2021年11月の一斉リスクオフ）。2026-09-02の南都銀行分析(本ファイル上部)で検証した
「DUKE。緊急メッセージ（警戒モードへ引き下げ）」は今回で初めて見た運用ではなく、**DUKE。塾が過去から
繰り返し使ってきた標準運用フロー**だったと確認できた。実務は「利益が乗っている玉から順に、無理せず利確幅を
確保して縮小する」であり、含み損玉を投げるという意味ではない。

#### `[INSIGHT]` 損小利大が数字として明確に裏付けられた。負け取引はおおむね-4.8%〜-11%、勝ち取引は+7%〜+212%
明確なマイナス着地はトレジャーファクトリー(-8.4%)・スクウェア・エニックス(-4.7%)・ダイレクトマーケティングミックス
(-5.5%)・アクシージア(-10.0%)・ディップ(-4.8%)・テスHD初回(-11.0%、ただし2回目で挽回)の6件のみ。
残り33件はすべてプラス（0.3%〜212%）。**負けを10%前後に収め、勝ちは青天井にする」という損小利大の設計思想が、
実際の39件のスプレッドとして定量的に確認できた。**

#### `[INSIGHT]` IPOセカンダリー投資は別ジャンルとして明確に区別されており、判断軸ファイルに未収録
Arent(#35)・トヨコー(#37)は「チャートがほぼ使えないため難易度は飛躍的に高まるが、ファンダメンタルズ重視で投資」
と明記される独立した手法。上場直後で移動平均線が引けないため、トレンドテンプレートは実質使えない。
代わりに目論見書・成長可能性資料から予想EPSを複数シナリオ（PER50/60/70等）で見積り、上値レンジを出してから
公開価格との倍率で割安性を判断している。**これは現行の`新高値ブレイク_判断軸.md`にも`目標株価の算定_DUKE式と
上原式.md`にも独立項目として存在しない。** 上原式のEPS×PER発想がここでは主戦場になっている点は接続点として興味深い。

#### `[INSIGHT]` 高PER・直近IPO銘柄の失敗は「BOX底拾いへの修正」という具体的な反省を残している
アクシージア(#16、2021.2上場・PER高)は通常のカップチートブレイクで入って決算後-10%損切り。要点メモに
「当銘柄は中長期的な中国の高級化粧品市場の伸びを取りに行く銘柄なので、再度買いに入る場合は、BOXの底を
拾いに行くエントリーに修正する」と明記。**新高値ブレイクを追うより、直近IPO・高PER銘柄はボックス底の
反発を待つ方が合理的、というDUKE。自身の実戦での軌道修正**。判断軸§3「ボックス底の押し目買い」の
適用対象を「銀行株のような伝統業種」だけでなく「高PER・直近IPOのグロース株」にも広げられる可能性がある。

#### `[INSIGHT]` 決算をまたがずに事前利確する判断が複数回、明示的な理由つきで登場
Terra Drone(#39: 5/15決算発表予定だったが急騰のため5/12に前倒し全売却)、テスHD②(#38: 5/15ザラ場決算発表予定
だったが急騰のため無理せず売却)、プログリット(#32: 決算リスクを抑制する目的で複数回に分けて利益確定)。
**含み益が大きい状態で決算をまたぐこと自体をリスクと見なし、決算直前に利確する判断が独立したパターンとして
繰り返される。** 判断軸の売却ルール§5には決算またぎの扱いが明記されていないため、追記の余地がある。

#### `[INSIGHT]` 同一銘柄で複数回トレードする「回転商い」が最大の利益源になり得る
レーザーテック(#21)は2020.4〜2021.7の間に4回エントリー・エグジットを繰り返し、通算341日で+29.1%。
壽屋(#26)は75日間に3サイクル回して+43.0%（うち1回は-7.8%損切りを含む）。**1回のブレイクで乗り切るのではなく、
BOX形成→ブレイク→利確→次のBOX形成→再ブレイクの反復を狙う運用が、個別のワンショットより収益機会を
増やしている。** ウォッチリストに一度入れた銘柄は、利確・損切り後も外さず監視を継続する価値が数字で裏付けられる。

### [INSIGHT] 市況関連株にPEGを当てはめると、分子・分母の両方が壊れる

- **分母**: 会社が通期を出さない＝期待成長率が一意に決まらない。さらに減益シナリオでPEGは
  マイナス、横ばいで定義不能になる。市況株では減益が現実的な選択肢なので、
  **PEGが定義できない領域に日常的に入る**。
- **分子**: 同じ株価・同じ会社で、EPSの取り方だけでPERが7倍〜270倍（38倍）動く。
  ピーク利益基準7倍、TTM 21.5倍、サイクル平均270倍。
  **どのEPSを「正常」と決めるかで答えが決まる**ため、PEGは分析ではなく前提の言い換えになる。
- 本銘柄は直近5期のうち**2期が赤字**（FY23/3 ▲266.94、FY24/3 ▲470.97）。
  赤字期はPEG定義不能。PEGが計算できる期とできない期が交互に来る会社には構造的に合わない。

### [INSIGHT] セクター全員が同じ低PEGなら、その数字は銘柄選別の情報を持たない

2026-09-05 stockanalysis.com 取得値: キオクシア0.05 / Micron 0.04 / SanDisk 0.21 / SK hynix 0.05。

**低PEGはキオクシア固有の割安さではなく、NANDセクター全体に付いている値札。**
低PER・低PEGを見たら、まず「同業他社も同じか」を確認する。同じなら選別情報はゼロ。

### [INSIGHT] 外部サイトのPERは内部整合を検算してから使う

stockanalysis.com の予想PER 4.18倍は、逆算すると予想EPS 13,029円 → 純利益6.92兆円 →
コンセンサス売上10.11兆に対する**純利益率68.4%**となる。FY27/3 Q1の実績純利益率は47.7%
（税引前69.9%、実効税率約31.8%）で、**税引後に68%は成立しない**。
そのため当方の計算には採用せず「サイトの表示値」として注記付きで並べるにとどめた。
**外部サイトの予想PERは、売上・利益率・株数に割り戻して整合を確認してから使う。**

### [INSIGHT] 株式分割はPER・PEGに影響しない

株価とEPSが同率（1/3）で動くため倍率は不変。影響するのは金額表示のみ。
分割前後で読み替えが要るのは株価・EPS・目標株価の絶対額だけで、
PER・PEG・成長率はそのまま使える。前回メモの「分割調整に注意」は絶対額にのみ適用される。

### IRバンクコネクタの引数のクセ（スキルに記録済み）
- `get_price_history` / `get_weekly_margin_balance` / `get_valuation_metrics_history`: `security_code` は**5桁**（4203→42030、285A→285A0）
- `get_financials`: `edinet_codes` は**配列**。`mode:"quarter"` を渡しても年次が返ることがある
- `list_shareholders` / `list_disclosures` / `list_segments`: `edinet_code` は**単数形の文字列**
- `get_price_history` は**1年分が上限**（200日線の実数はここでは出せない）
- **IRバンクは個別銘柄DB。日経平均・TOPIXの指数を持っていない → Mは常に別ソース**
- `eps` は as-reported（分割未調整）。期をまたぐ比較は `eps_adjusted`
