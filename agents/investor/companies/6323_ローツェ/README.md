## 学び

- **2026/06/10**: 最初のエントリーは新高値付近で入り、10%超の損切りに。
  → 「新高値付近でinしたが、**もっとローリスクなエントリーポイントがあった**」（2026/07/07の反省）
- **2026/07/22**: 「欲張らずにいったんノーポジションにしたのはよい経験」。4,800〜900の場面で
  「午後上がるかも」と持ち越したのは反省点
- **2026/08/04**: 3,300まで下がって**損切ルールを守らなかったが運良くプラスに戻った**。
  本人が「たまたまのトレード」と明記している。**結果が良かった規律違反は、最も危険な成功体験**
- 4,200をボックス底と繰り返し判断したが、2回とも下抜けた（6月・7月末）。
  **同じ水準をサポートと見なす判断が2回続けて外れている**
- **2026/09/04時点の答え合わせ**: 8/4手仕舞い（4,169円）後、株価は8/5に一瞬+7.9%（4,498円）まで戻したが、
  以降下降基調に転じ9/4時点で3,750円（手仕舞い値から**-10.0%**）。**結果的に見て8/4の手仕舞いは早すぎたのでは
  なく、その後の下落局面を回避する形になっていた。** ただし規律の評価は変わらない。「規律違反・結果的には
  タイミングも良かった」の両方を記録する（自分のルール.md §3「ルール違反が結果オーライで終わる」の実例）
