## この事例が示す構造的な問題

| # | 問題 | DUKE。式の該当ルール |
|---|---|---|
| 1 | **目標株価が「？」で未設定** | 上値余地が分からないままエントリーしている＝リスクリワードが計算できない |
| 2 | **ポジションサイズが動機ベース**（「やってみたかった」） | 5分の1ルール（試し玉＝総資金の1/25）から逸脱 |
| 3 | **損切りルール違反**（▲11.6%） | 「最大でも10%まで」「100株でもいいので逆指値注文を入れておく」 |
| 4 | 金額の大きさが判断を歪めた | ポジションサイズが適正なら「神頼み」にならない。**3は2の結果**である |

> **因果の順序が重要。** 損切りを守れなかったのは意志の問題ではなく、
> **ポジションサイズが大きすぎたことの結果**。再発防止はメンタルではなくサイズで行う。
> 2026/08/14の南都銀行で「打診100株に留めた」判断は、この教訓が効いた結果と読める。
