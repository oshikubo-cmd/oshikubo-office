# 銘柄カルテ（企業データベース）

銘柄ごとに積み上がるストック情報を置く。時系列のログは投資日記（Googleドキュメント）が正本で、
**ここは「その銘柄について自分が何を知っているか」を一望するための場所**。

上原式の「企業データベース」（企業ごと・決算期ごとに1ページ）に相当する
（[../knowledge/目標株価とバリュエーション_上原式.md](../knowledge/目標株価とバリュエーション_上原式.md)）。
Notionではなくここに置く理由は、判断軸ファイルと同じ場所にあり、gitで履歴が残り、
プライベートPCへの移設時にディレクトリごと動かせるため。

## 構成

```
companies/
    <コード>_<社名>/
        README.md      ← 銘柄カルテ。常に最新の見立て。上書き更新する
        2026Q2.md      ← 決算期ごとのページ。追記のみ（任意）
```

## 使い分け

| 情報の性質 | 置き場 |
|---|---|
| 時系列ログ（その日何をしたか・学んだか） | 投資日記（Googleドキュメント） |
| **銘柄ごとに積み上がる情報** | **ここ** |
| 判断のフレームワーク | `../knowledge/` |
| 分析セッションの記録 | `../memory/raw.md` |

## カルテの更新タイミング

- 売買したとき（日記エントリを書くのと同時）
- 決算が出たとき（目標株価の再算定＝DUKE。式の「四半期ごとの答え合わせ」）
- 判定が変わったとき（ステージ・トレンドテンプレートの合否）
- IR取材や説明会で新しい情報を得たとき

## 注意

- **数値には必ず出典と取得日を書く**
- 「事実」と「自分の見立て」を分けて書く
- 投資助言・売買推奨は書かない。判断材料の整理までにとどめる
- 初期版は投資日記の記録から起こしたもの。**株価・財務数値は日記記載時点のものであり、
  現在値ではない**。分析に使う前にIRバンクコネクタ等で再取得すること
