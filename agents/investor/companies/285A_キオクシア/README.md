## 論点（なぜこの銘柄か）

- **フォロースルーデーが出た**（相場環境の判定）
- PERは割安
- 単元（100株）はリスクが大きいため**ミニ株で**。「少しもっておきたかった」

> ⚠ 本人が「**単元はリスクなので塾はNGだがミニ株で**」と明記。ルール外の取引であることを自覚している。
> ミニ株のため逆指値注文が使えない可能性がある点に注意（損切りの機械化ができない）。

## 逃した経験（2026/06/19の記録）

- 株価が10万円を超えた。2025年9月の株価が2,000円だったので**50倍**
- 2025/10/02に5,410円で株探に登録していた。「この時に1,000万のうち200万を投資していれば4,000万になってた」
- そこから得た教訓:
  - **「株価は待ってくれないのですぐに投資できる資金があることが大切。種銭がなければ勝負ができない」**
  - 「負けないのは分散投資だけど、儲けるのは集中投資」
  - 「10バガーを早く掴みたい」

> ⚠ この教訓は**DUKE。式のリスク管理（5分の1ルール・最大5銘柄）と正面から衝突する**。
> 「儲けるのは集中投資」は事実だが、DUKE。式は「生き残るのが最優先、儲けるのはその後」。
> 50倍を逃した悔しさが次の取引のサイズを歪めないよう注意が必要。
>
> **2026-09-04 追記**: その後、株価は 2026-06-22 に 112,700円で天井を打ち、
> 7/30に36,020円まで **▲68%** 下落した。「逃した」と感じた高値圏で入っていた場合、
> 損失は10%ルールでは収まらなかった（1日で▲16%の日がある）。
> **逃した後悔は、入らなかったことの正しさとセットで記録しておく。**
