## 目標株価

「1.5倍で2,737円」は**機械的な1.5倍計算であり、算定していない**。
[../../knowledge/目標株価の算定_DUKE式と上原式.md](../../knowledge/目標株価の算定_DUKE式と上原式.md) §3-4 の手順で算定し直す必要がある。

なお保険・金融セクターは、DUKE。式の営業利益倍率が使いにくい業種（営業利益の概念が事業会社と異なる）。
**この銘柄については上原式（EPS×PER）またはPBR・修正PBR基準の方が適合する可能性が高い。**
