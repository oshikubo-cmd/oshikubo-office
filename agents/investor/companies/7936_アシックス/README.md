## 2026-09-06 深堀分析で新たに確認した事項（IRbank・SMBC日興証券レポート3件より）

- **実効税率**: 26/12期・27/12期のSMBC日興予想はいずれも約30.0%（税前利益に対する法人税等の比率から算出）。DUKE式換算が前提とする33%との乖離が、上原式目標株価（6,000円）とDUKE式検算値（約5,497円、乖離約9%）の主因の一つと確認
- **自己株式取得**: キャッシュフロー計算書ベースで26/12期以降も年間約500億円規模の取得を継続する前提（24/12期350億円→25/12期以降500億円/年）
- **棚卸資産**: 25/12期実績で前期比+30.1%（179.0十億円）と、売上高の伸び+19.5%を上回るペースで増加した事実を確認（乖離+10.6pt）。IR質問リストの主要論点の一つ
- **競合比較（国内）**: アシックスはPER25.0倍・PBR8.8倍・ROE42.4%・EPS3年CAGR72.0%で、ヨネックス（PER17.7倍・ROE17.2%）・ミズノ（PER15.9倍・ROE11.7%）・ゴールドウィン（PER12.8倍・ROE19.5%）を上回る（2026-08-27付ブルームバーグコンセンサス、SMBC日興証券レポート）
- **競合比較（海外）**: ナイキ・アディダス・On・デッカーズ・Dick'sは直近1年株価騰落率がいずれもマイナス（-12%〜-46%）。ただし過去5年（2021/9基準）ではアシックス+580%・ミズノ+347%・ヨネックス+228%と国内3社が海外同業を圧倒
- **在庫日数（DIO）業界比較**: アシックスの2025年DIOは164.9日（SMBC算出、棚卸資産期首期末平均÷売上原価×365）。2023年171.3日→2024年158.1日→2025年164.9日と下げ止まり傾向。Nike(103.3日)・Yonex(88.5日)より高く、Adidas(164.5日)・Mizuno(145.5日)と同水準
- **反発の失敗パターン**: IRBANK日次OHLCで検証した結果、8/20（レンジ内位置100%の教科書的反発日）が8/21に失敗、8/28（同90%）も8/31に失敗と、2回連続で反発が続かなかった事実を確認。9/4の反発（同81%）は3回目の試みであり、現時点では確定していない
