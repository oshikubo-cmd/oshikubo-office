## 2. 業績（4ポイント判定）

出典: IRBANK（TDnet/EDINET）。単位=百万円、J-GAAP単体。

| # | 基準 | 判定 |
|---|---|---|
| ① 利益の安定性 | 年率5〜10%以上を維持、大幅減益なし | ✓ 通期OP 909→1,136(+25.0%)→1,537(+35.3%) |
| ② 直近1〜2年のOP伸び20%以上 | ✓ | FY2024 +25.0% / FY2025 +35.3% |

| ④ 売上高営業利益率の前年同期比 | **△** | 26Q1 50.0%→45.5%（**-4.5pt**）、26Q2 48.5%→49.4%（+0.9pt） |

**業績の実態: 売上の伸びは維持しているが、営業利益の伸びが1年かけて減速した。**
四半期OP YoY: +61% → +40% → +38% → **+9% → +15% → +24%**。
26Q2で持ち直したが、**成長減速の事実が株価-43.8%の主因**である。

### 会社計画（FY2026・修正なし）

売上 **4,277百万（+26.1%）** ／ 営業利益 **1,927百万（+25.4%）** ／ 配当21円

- 1H進捗: 売上 46.6% ／ **営業利益 49.1%**（1H OP 946、計画比+35百万の上振れ）
- **⚠ 2H要求成長率**: 2H OP = 1,927 - 946 = **981百万**、前年2H 750百万に対し **+30.8%**。
  1H実績は **+20.1%** であり、**会社計画は2Hでの加速を前提にしている**。
  「会社計画をそのまま信じない」原則からは、**保守側に置き直す必要がある**（下記）。

## 3. EPS × PER 象限（上原式）— 利益の源泉の分解

```
株価 = EPS × PER
```

| 時点 | EPS(実績) | 期末PER | 株価 |
|---|---|---|---|
| FY2023末 | 43.06 | **46.7倍** | 2,011 |
| FY2024末 | 53.83 | **36.5倍** | 1,965 |
| FY2025末 | 71.75 | **36.5倍** | 2,622 |
| 現在(26/09/01) | 71.75(実績) / 89.4(予想) | **30.5倍 / 24.5倍** | 2,191 |

※PER5年平均 43.5倍（IRBANK）。FY2025の年間PERレンジは 24.0〜42.0倍。

**判定: 「ピークアウト」象限（利益↑ × PER↓）＝ 🔴ショート目線の象限。**
内訳は上原の分類でいう **①成長減速**（②需給剥落ではない）。

**利益の源泉の分解（ここが本件の核心）**:

- EPS は 43.06 → 53.83 → 71.75 → 予想89.4 と **一度も止まらず伸びている**
- にもかかわらず株価は 2025-11 の 3,015円から -27% 。**下落は100%がPER縮小によるもの**
- 3,015円時点のPER（FY2025 EPS 71.75）は **42.0倍**。現在は実績30.5倍・予想24.5倍
- **つまり市場は「EPSは伸びるが、伸び率が落ちた」と評価してマルチプルを剥がした**

**→ 上原の「いい投資アイデア4条件」②「なぜ株価に織り込まれていないのか」に対する答えが、
現時点では出せない。** 割安に見えるのは織り込み漏れではなく、**成長減速を織り込んだ正当なディレーティング**
である可能性が高い。ここが説明できるようになるまでは買い理由にしない。

象限の移動として狙うなら「ピークアウト → GARP → モメンタム」であり、
**その転換点は26Q2のOP+24.3%回復が3Q・4Qで継続するかどうか**にある。

## 4. 上値余地（目標株価）

**対象判定**: 成長株（市況関連株でも景気循環株でも業績悪化中でも赤字でもない）→ **DUKE。式の算定対象**。

### 前提

| 項目 | 置いた値 | 根拠 |
|---|---|---|
| 予想営業利益（通常） | **19.27億円** | 会社計画（FY2026、修正なし） |
| 予想営業利益（弱気） | **18.45億円** | 1H実績のYoY+20.1%が2Hも続くと仮定。会社計画比 -4.2% |
| 予想EPS | **89.4円** | OP19.27億 × 純利益/営業利益 0.708（FY2025実績）÷ 発行済15,251,838株 |
| 適正倍率 | **営業利益倍率22倍（PER換算33倍）** | 自社の過去期末水準26倍（FY24末26.2倍・FY25末26.0倍）と現在17.3倍の中間 |
| 上限倍率 | **26倍（PER換算39倍）** | FY2024末・FY2025末の自社水準 |
| 現在の倍率 | **17.3倍**（時価総額334.2億 ÷ 19.27億） | TTM実績ベースでは19.7倍 |

### 時価総額マトリックス（億円 / 株価）

| 通期OP | 16倍 | 20倍 | **22倍** | **26倍** |
|---|---|---|---|---|
| 18.5億（弱気） | 296億/@1,941 | 370億/@2,426 | 407億/@2,669 | 481億/@3,154 |
| **19.27億（会社計画）** | 308億/@2,022 | 385億/@2,527 | **424億/@2,780** | **501億/@3,285** |
| 20.0億（強気） | 320億/@2,098 | 400億/@2,623 | 440億/@2,885 | 520億/@3,409 |
| 23.1億（FY27想定+20%） | 370億/@2,423 | 462億/@3,029 | 508億/@3,332 | 601億/@3,938 |
| 27.8億（FY28想定+20%） | 445億/@2,916 | 556億/@3,645 | 612億/@4,010 | 723億/@4,739 |

### 2段の目標株価（FY2026ベース）

| | 株価 | 現値からの余地 |
|---|---|---|
| **適正株価** | **@2,780**（OP19.27億 × 22倍） | +26.9% |
| **アップサイド株価** | **@3,285**（OP19.27億 × 26倍＝自社過去2年の期末水準） | +49.9% |
| 弱気シナリオ | @1,941（OP18.45億 × 現状倍率16倍） | -11.4% |

### 上原式での検算

```
適正株価     予想EPS 89.4円 × 適正PER 31倍 = @2,771   （DUKE。式 @2,780 とほぼ一致 ✓）
アップサイド 予想EPS 89.4円 × 上限PER 36.5倍 = @3,263 （DUKE。式 @3,285 とほぼ一致 ✓）
```

**換算のズレの中身**: 判断軸の換算式 `PER ≒ 営業利益倍率 × 1.5`（法人税率33%前提）に対し、
eWeLLの実係数は **1.41**（純利益/営業利益 = 0.708）。差分は **実効税率が約29%と低め**であることと、
営業外損益がほぼゼロ（FY2025: 営業1,537 → 経常1,547、特別損益ゼロ）であることによる。
**EPSにノイズがほぼ入らない会社**なので、2方式が近い値になるのは整合的。

### PEGレシオ

予想PER 24.5倍 ÷ 会社計画の営業利益成長率 25.4% = **PEG 0.96**（1以下＝割安側）。
ただしこれは会社計画の成長率を使った値。**2Hが未達なら成長率は20%前後に落ち、PEGは1.2程度に悪化する。**

## 5. リスク（仮にブレイクした場合の設計）

**現時点はステージ1でエントリー対象外。以下はブレイクが出た場合の事前設計。**

- **想定ピボット: @2,397**（2026-08-14の日中高値。決算ギャップアップ日の高値）
- 現在のボックス: 概ね **2,046 〜 2,397**（8/14以降13営業日）
- 損切り: 8% → **@2,205** ／ 10% → **@2,157**（ボックス下限2,046より上なので8%が実質的な外枠）

| 目標 | 上値 | RR（損切り8%時） |
|---|---|---|
| 適正株価 @2,780 | +16.0% | **1 : 2.0** |
| アップサイド @3,285 | +37.0% | **1 : 4.6** |

上原の水準（低リスク: +30〜40% / ▲10〜20%）に照らすと、アップサイドまで見れば**低リスクの投資アイデアの範囲**。

### 最大の懸念事項

1. **会社計画の2H要求が+30.8%成長**（1H実績+20.1%）。3Q決算で未達が見えると再びPERが剥がれる
2. **営業利益率の維持**。26Q1に50.0%→45.5%と4.5pt低下しており、増員・投資フェーズに入っている可能性
3. **成長減速が構造的か一時的かが未確認**。四半期OP YoYが+61%→+9%まで落ちた原因を分解できていない

### その他のリスク・不利な事実（省略しない）

- **時価総額334億円**。DUKE。の「10倍株は時価総額200億円未満を狙う」水準を既に超過している
- **2026-08-31に出来高122,500株（25日平均の2.6倍）で陰線**。高値圏の出来高増を伴う下落は注意サイン
- **ベースの出来高が枯れていない**。8/14以降の出来高は平均を上回る水準で推移しており、
  押久保の最重要判断軸「保ち合い終盤で出来高が枯れているか」を**満たしていない**
- 条件⑧（6週で指数より強い）は +7.7% vs +6.8% と**僅差**で、強い相対力とは言えない
