# 表記ルール・チェックリスト

翔泳社の正式ルールと単独メール固有の運用ルール。納品前に全項目を確認する。

## 人名・社名（単独メール固有）

- [ ] カタカナ人名は**中黒（・）区切り**にする。例）ジョン・コリソン、エミリー・サンズ
      LPが半角スペース区切り（ジョン コリソン）でも中黒に直す。媒体ルールがLP表記より優先
- [ ] 日本人名の姓名間スペースは**LP表記に合わせる**。例）南場 智子氏、翁 素文氏
- [ ] 社名は**LPの正式表記**に合わせる。例）本文はディー・エヌ・エー（株式会社ディー・エヌ・エー）、
      LegalOn Technologies（LegalOnと略さない）
- [ ] タイトル（件名）内は字数の都合で略称可。例）DeNA南場氏
- [ ] 役職はLP表記を一字一句そのまま。例）代表取締役社長 兼 CEO
- [ ] 外部登壇者には「氏」を付ける。クライアント社員にも媒体名義のメールでは「氏」を付けてよい
- [ ] **登壇者を紹介する箇所には、肩書き・所属をサイト掲載表記のまま必ず入れる**。
      BtoBメディアの読者にとって肩書き・所属は重要情報。氏名だけの紹介は不可
      （2026-08-07 PKSHA案件FB: 東京海上日動の肩書き欠落を指摘された）
- [ ] **講演・セッションタイトルはLP表記と一字一句一致させる**（（仮）や記号も改変しない）。
      WebFetchの自動抽出はタイトルを省略・改変することがあるため、
      引用する場合はブラウザ（get_page_text）等でLP原文を必ず確認する
      （2026-08-07 PKSHA案件FB: 村田製作所の講演タイトル相違を指摘された）
- [ ] LPにセッションタイトルが未掲載の場合は、タイトルを創作せず
      「肩書き＋氏名＋による講演」の形で紹介する

## メール固有の禁止事項

- [ ] プリヘッダーを作らない（件名末尾の媒体タグでプレビュー領域が埋まるため）
- [ ] 「——」（ダッシュ）を使わない。句読点や文の切れ目で置き換える
      （LP由来の正式セッションタイトル内の「――」はそのまま）
- [ ] 事実の捏造をしない。LP・素材にない情報は `[要確認]` を付けて明示する

## 数字表記

- [ ] 数字・英字は半角（2文字以上。ウェブ・メールでは1文字も半角）
- [ ] 4桁の数字は3桁の左に半角カンマ（西暦年を除く）。例）1,000
- [ ] 5桁以上は「万」「億」「兆」を用いる。例）12兆3,456万7,890円
- [ ] 日付は原則西暦。元号は括弧で補足
- [ ] ばくぜんとした数は漢字表記（数百人）。「～」を使う場合は算用数字可（2～3人）
- [ ] 分数は「2分の1」（「1/2」不可）
- [ ] 月数は「○ヵ月」（小さな「ヵ」）
- [ ] 副詞的な数は漢数字（三つの原因）。「一つひとつ」と後ろをひらく
- [ ] 「￥」は使わず「円」。例）5,000円

## 記号表記

- [ ] 記号は原則全角。例）（）「」［］“”！？％＆＃＄・
- [ ] 「！」「？」の後は全角スペース1つ。**ただしタイトル（件名）内は不要**
- [ ] 「！！」「！？」と2つ続く場合は「!?」と半角にし、後に全角スペース1つ
- [ ] 「」の中の「」は『』にする
- [ ] 「」や（）内の文末に句点を入れない（`」。` `。）` 禁止）
- [ ] ダブルクオートは「“」ではじまり「”」で終わる
- [ ] スラッシュは全角「／」（URLを除く）
- [ ] 波ダッシュ・時刻範囲は全角「～」。例）8:30～17:45

## 開催概要の表記（過去案件の慣例）

- [ ] 曜日は半角括弧: `2026年9月30日(水)`（記事の全角記号原則の例外。過去メールの慣例に従う）
- [ ] 曜日は必ず自分で検算する（LP抽出の曜日は誤ることがある）
- [ ] 参加費がLPに明記されていなければ「無料（事前登録制）」等の推測値に `[要確認]` を付ける
