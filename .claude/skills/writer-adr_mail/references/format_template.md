# 単独メールの定型フォーマット

過去案件（PKSHA AI Summit、ZVC/Zoom、セールスフォース、Stripe Tour Tokyo）で確立した構成。
この順序と区切り記号を守ることで、Cuenote入稿時の体裁と読者の読み慣れたリズムが保たれる。

## ファイル全体の構造

```
０１２３４５６７８９０１２３４５６７８９０１２３４５６７８９０１２３４
▼タイトル
（タイトル。確定前は「タイトルA」「タイトルB」等で複数案を並べる）


本文＝＝＝

（以下、本文）
```

- 1行目のルーラー（全角数字35字）は1行の長さとタイトル字数の目安。**必ずこのまま入れる**
- タイトルが複数案の段階では `タイトルA` `タイトルB` の見出しで並べ、確定後は `▼タイトル` 1本にする

## 本文の構成（この順で書く）

### 1. 挨拶（固定）

```
こんにちは。AIdiver編集部です。
```

配信媒体が異なる場合は編集部名を差し替える。

### 2. 冒頭フック（3〜6行）

読者の課題や時代の変化を短く提示し、「今回は◯◯をご紹介します」でイベント紹介につなぐ。
売り込みではなく「編集部が見つけてきた価値ある情報」のトーンで書く。

### 3. イベント名＋URL

```
●イベント名（正式名称。サブタイトルがあれば2行目に全角スペース字下げで）
https://（飛ばし先URL）
```

### 4. おすすめボックス（固定枠）

```
▼▽▼━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【こんな方におすすめです】
・（ターゲット読者の課題・欲求を3つ。「〜したい」で終える）
・
・
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━▲△▲
```

罫線は「━」34個。3項目の文字数感をそろえると読みやすい。

### 5. 見どころ本文（20〜30行）

イベントの魅力を具体的に。使える型:

- 登壇者押し: 基調講演・対談の顔ぶれを役職つきで紹介
- 主推しセッション: 「AIdiver読者の皆さまに特に注目いただきたいのが」で1本を深掘り
- 箇条書き: 「このほかにも、」＋学べるトピック3〜4個＋「など、」で受ける
- 会場・ネットワーキング: リアル開催ならその価値にも触れる

### 6. 申し込みCTA（固定枠）

```
▼▽▼申し込みはこちら▼▽▼
https://（飛ばし先URL）
```

### 7. 締め（2〜3行）

イベントのテーマを読者の行動につなげる一言。「ぜひ会場で見つけてください。」等。

### 8. 開催概要ボックス（固定枠）

```
▼▽▼━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[開催概要]
・イベント名：
・日時：2026年9月30日(水) 8:30～17:45　※曜日は半角括弧、検算必須
・会場：（リアル開催の場合。住所も）
・形式：会場開催（リアル）／オンライン（ウェビナー）
・参加費：無料（事前登録制）　※LPに明記がなければ [要確認] を付ける
・主催：（LPの表記どおり）

詳細・お申込みはこちら
https://（飛ばし先URL）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━▲△▲
```

お問合せ先がLPにあれば主催の下に追加してよい。

## 数値の規定

- 本文は `本文＝＝＝` の次の行から数えて100行以内。標準60〜70行
- 1行は全角35字以内（半角0.5換算）
- 飛ばし先URLは本文中に3回登場する（イベント紹介・CTA・開催概要）
