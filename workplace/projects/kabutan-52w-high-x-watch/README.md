# 新高値トップ10 × X話題ポスト デイリーウォッチ

株探「本日、52週高値を更新した銘柄」の**前日比率トップ10**について、
X（旧Twitter）で話題になっている投稿を拾い、毎営業日18時に Slack 自分宛DMへ送る仕組み。

用途は押久保の個人投資（第3ドメイン）の情報収集。売買推奨ではなく「今日どの銘柄が
どんな材料で騰がり、X上でどう語られているか」を毎日1本のDMで把握することが目的。

## 運用仕様

| 項目 | 内容 |
|---|---|
| 頻度 | 平日18時（cron `0 18 * * 1-5`） |
| 通知先 | Slack 自分宛DM（`UMNRD48V8`） |
| 対象 | 52週高値更新銘柄のうち前日比率上位10 |
| X投稿 | 各銘柄3〜4件収集し、エンゲージメント上位1〜3件を採用 |
| 通知条件 | 毎回送る（該当ゼロでもその旨を送る） |
| 履歴 | `log.md` に毎回1行以上追記 |

18時にしているのは、大引け（15:30）後でその日の52週高値リストが確定し、
かつPTS（夜間取引）の初動やXの引け後の反応まで拾えるため。

## データソース

### 1. 株探（銘柄リスト）

```
https://kabutan.jp/warning/record_w52_high_price?&market=0&capitalization=-1&stc=code&stm=1&col=zenhiritsu
```

`col=zenhiritsu` で前日比率降順。1ページ15件表示なので、**1ページ目の上位10行**を取ればよい。
ページャを追う必要はない。取得カラム: コード / 銘柄名 / 市場 / 株価 / 前日比 / 前日比率 / PER / PBR / 利回り。

### 2. Yahoo!リアルタイム検索（X投稿）

```
https://search.yahoo.co.jp/realtime/search?p=<銘柄名> OR <コード>
```

**X本体の検索（x.com/search）はログイン必須で使えない**（未ログインだとログイン画面にリダイレクトされる）。
Yahoo!リアルタイム検索はログイン不要でXの投稿を本文・投稿者・RT/いいね数・投稿時刻つきで返すため、
これを唯一の取得経路とする。1クエリあたり約40件（直近の新着順）が取れる。

## 処理フロー

1. 株探ページを navigate し、`snippets.md` STEP 1 で上位10銘柄を取得
2. 各銘柄について Yahoo!リアルタイム検索を navigate → STEP 2 で投稿を抽出（10回ループ）
3. 銘柄ごとにエンゲージメント（いいね + RT×3）上位から、内容のある投稿を1〜3件選ぶ
4. 全体を読んで「今日の地合い（共通テーマ）」を1〜2文にまとめる
5. Slack DM を送信
6. `log.md` に追記

## クエリの作り方

株探の銘柄名は略称（「アイサンテク」「トーメンデバ」「日本一ソフト」「インテージＨ」など）なので、
**わかる範囲で正式名称に展開してから** `<名称> OR <コード>` の形で検索する。
コードを OR で入れておけば、名称展開に失敗しても株クラの投稿は拾える。

展開例: アイサンテク→アイサンテクノロジー / トーメンデバ→トーメンデバイス /
日本一ソフト→日本一ソフトウェア / タングス→日本タングステン / ダイナマップ→ダイナミックマップ /
鶴見製→鶴見製作所 / 大分銀→大分銀行 / インテージＨ→インテージ（全角ＨやＨＤは落とす）

## 既知の制約・ノイズ

### 1. 一般名詞と同じ銘柄名はノイズが多い

「ヴィッツ」（トヨタの車種・ミニカー・アニメキャラ名）、「シード」（コンタクトレンズ／一般語）など。
対策として、投稿本文に株式文脈のキーワード（株・銘柄・S高・ストップ高・急騰・決算・PTS・出来高・
上場・投資・チャート・寄り・終値・材料・東証・円台・`(1234)` 形式のコード）を含むものだけを残す
フィルタを `snippets.md` STEP 2 に組み込んである。

フィルタ後の件数が極端に少ない（0〜2件）場合は「Xでは話題になっていない」という事実として報告する。
無理に投稿をひねり出さない。

### 2. 煽り・アフィリエイトアカウントが上位に来る

「【日本株】来るぞ、大急騰」「明日のSTOP高予想銘柄」「俺の投稿だけ見ておけ」といった
エンゲージメント稼ぎのアカウントが、いいね数では上位に入りやすい。
これらは**話題度の指標としては採用してよいが、内容は鵜呑みにしない**。
DM末尾に「どれが事実ベースの材料か」を1行で添えること（例: 日経報道・適時開示・出来高データ）。

同一文面を複数アカウントがコピペしているケースもある（テンプレ拡散）。同文はまとめて1件扱いにする。

### 3. 材料の特定はX頼みにしない

急騰理由が投稿から読み取れないときは、株探の銘柄別ニュースや適時開示を確認して補う。
「理由不明」のまま出すより「材料は確認できず」と書くほうが有用。

### 4. 実行タイミング

スケジュールタスクは Claude Code アプリが起動している間に実行される。
アプリが閉じていた場合は次回起動時にまとめて実行されるため、翌日以降に届くDMは
日付が過去のものになりうる。DMの見出しには必ず**データの基準日**を書く。

### 5. 土日祝

平日（月〜金）のみの実行。祝日は株探のリストが前営業日のまま残るので、
実行時に「本日は休場」と判断できた場合はその旨を1行で送って終わる。
