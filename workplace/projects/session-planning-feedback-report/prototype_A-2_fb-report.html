3 イベント総括と次回への改善 全体データから導く、次回の企画・運営の論点
  1. 最大の伸びしろは「やや満足→満足」への転換。満足以上91%と体験の底は堅いが、Top-boxは50%。セッション間のTop-box差（12〜61%）が主因であり、下位群の底上げがイベント全体の評価を決める。本FBサイクル（PART II）はそのための仕組み。
  2. 「実践・解決編」への渇望が全セッション共通。次回希望テーマはAI活用事例・AIエージェント（技術寄り）・セキュリティ・モダナイゼーション。課題提起型セッションは集客するが、「で、どうやるのか」まで踏み込んだ企画が満足度上位に入る傾向。
  3. セッション外体験に未回収の価値がある。展示ブースは過半が「立ち寄らなかった／特にない」、懇親会参加は12%。セッションと回遊の導線設計（休憩時間の使い方・ブース連動企画）が次回の運営論点。
  4. 新規58.5%をリピートに転換する仕掛けを当日に仕込む。次回参加意向88.5%・否定0%と意欲は極めて高い。会期中の次回登録導線（クロージングでの告知・その場登録）で意向を実登録に変える。

効いた点

  • 「個人は速いのにチームは速くならない」構造の言語化・ボトルネック分析への評価が最多
  • 「実測1.1倍」という正直な数字への信頼と共感。同じ課題を抱える聴講者に強く刺さった
  • グラフ・数字を交えた構造的な説明のわかりやすさ

「実測値が1.1倍という点はとても興味深かった」

改善点

  • 具体性の不足 — 誰がどの作業をどう改善したか、測定方法への言及が薄い
  • 「1.1倍からどう改善したか」の解決編がなく消化不良、という声が複数
  • インパクトの強いタイトルが期待値を上げすぎ、内容とのギャップを生んだ
「その1.1倍という課題に対して具体的にどう取り組んでどれくらい改善したのかが聞きたかった」
「とてもインパクトのある頼もしいタイトルでしたので、大きく期待しすぎてしまいました」
F 次回への改善（このセッション企画） 全体傾向（PART I-3）×このセッションの声から導出
  1. 続編企画「1.1倍からの改善実践編」を立てる。課題提起は明確に刺さった（集客上位・共感コメント多数）。「答え」を求めた層が満足度を押し下げており、PART I-3で確認した「実践・解決編への渇望」とも一致する。次回の最有力企画。
  2. タイトルの期待値設計を仮説シートに組み込む。「何を約束し、何を約束しないか」を企画段階で明文化する。煽るなら回収する。回収できないなら副題で範囲を示す（例:「〜まず、ボトルネックの見つけ方」）。
  3. 登壇者ブリーフに「具体性の最低ライン」を入れる。測定方法・数字の根拠・実例を最低1つずつ。改善指摘9件のうち大半が具体性に集中しており、企画側のブリーフで防げる種類の不満。
  4. 同テーマは広い部屋割りを検討。立ち見が発生。テーマの集客力は実証されたため、次回は部屋のサイズをスコアに合わせる。
