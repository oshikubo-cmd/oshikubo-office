## 5. トーン・表現ガイド（今回の最重要要件）

### 5-1. 基本方針

1. **主語を「人」ではなく「仕事」にする**。「人がいらなくなる」ではなく「この作業がなくなる」
2. **引き算ではなく足し算で書く**。空いた時間・手が回らなかった領域・やりたかったことに接続する
3. **不安を書いたら必ず同じ節で解を書く**。不安の提示だけで節を終えない
4. **制度批評に踏み込まない**。雇用制度・解雇規制そのものへの評価は記事の役割ではない。各社が「自社の雇用を前提に、どう組み替えたか」という実践の記述に限定する
5. **断定を避け、各社の実践として書く**。「〜すべきだ」ではなく「〜社では〜という形を取っている」
6. **経営目線と現場目線を両方置く**。読者は経営層だが、記事は現場に読まれる前提で書く

### 5-2. 言い換え表（本文の地の文に適用）

| 避ける表現 | 使う表現 |
|---|---|
| 代替する／置き換える | 担い方を組み替える／手離れする |
| 人員削減／余剰人員 | 空いた時間の再配分／人にしかできない領域への再配置 |
| 仕事を奪われる | （地の文では使わない。発言引用で出た場合のみ、必ず解とセットで） |
| 不要になる | やらなくてよくなる／自動で回るようになる |
| AIに任せて人は要らない | AIに任せられる範囲が広がった分、人の判断が効く場面が増えた |
| 監視する／管理する | 何が起きたか説明できる状態にする／ログで辿れるようにする |
| ボトルネックは人 | 残った律速は、人が納得して決める時間 ※前向きな含意で使う |
| 生き残れない／淘汰される | 差がつく／選択肢が狭まる |
| 解雇規制／雇用の流動化 | （制度論には触れない。各社の実践記述に置き換える） |

### 5-3. 締めで必ず出したいメッセージの型

- AIエージェント組織は、**人を減らすためではなく、人の時間を何に向けるかを決め直すため**に作る
- 導入は速度より順序。安全に試せる場を先に作り、そこから広げる
- 経営が自ら触ることが、現場の不安をいちばん早く解く
